# 벽 오르기 4프레임 제작 기준

- `normal_wall_climb_motion_reference.png`는 ImageGen으로 만든 동작 참고 시트다.
- 실제 게임 아틀라스에는 기존 캐릭터별 픽셀, 장비, 신체 비율을 그대로 사용한다.
- 4프레임은 `접촉 → 당기기 → 높은 접촉 → 회복` 순서다.
- 위로 오를 때는 정방향, 아래로 내려갈 때는 역방향으로 재생한다.
- 입력 없이 매달릴 때는 첫 프레임을 고정해 불필요한 움찔거림을 막는다.
- 모든 프레임은 128×128, 고정 배율 `(1, 1)`, 오른손의 바깥 X=87 접촉선을 유지한다.
- 게임플레이 판정은 스프라이트와 무관한 공통 42×90 콜라이더를 계속 사용한다.
