# Block Fighter

테트리스 보드 안의 쿵푸 캐릭터가 블록을 밀고 회전시키는 Godot 4.7.1
프로젝트입니다. 밝은 UI, 블록 스프라이트와 프레임 기반 캐릭터 애니메이션을 사용합니다.

## 실행

1. Godot 4.7.1에서 저장소의 `project.godot`을 가져옵니다.
2. 프로젝트를 연 뒤 `F5`를 눌러 실행합니다.
3. 시작 화면에서 `GAME START`를 선택하고 캐릭터를 확정합니다.

명령행에서 Godot을 사용할 수 있다면 저장소 루트에서 다음 명령으로 실행할 수 있습니다.

```sh
godot --path .
```

프로젝트 시작 장면은 `start_screen/scenes/start_screen.tscn`이며 게임 진입 시
`scenes/main.tscn`을 불러옵니다.

## 주요 조작

| 입력 | 기능 |
| --- | --- |
| `←/→` 또는 `A/D` | 좌우 이동 |
| `Z` 또는 `Space` | 점프 |
| 바닥에서 `↓` 유지 | 명상, 블록 진행 속도 2배 |
| 벽에서 `C` 유지 | 매달리기 |
| 매달린 상태에서 `↑/↓` | 벽을 따라 이동 |
| 매달린 상태에서 `Z/Space` | 벽 점프 |
| `X` | 캐릭터별 무기로 전방 블록을 정확히 1칸 밀기 |
| `V` | 선택 캐릭터의 특수 스킬 사용 |
| `S` | 가까운 활성 블록 플립 |
| `Q` 1초 유지 | 목숨 1개를 소비하고 상단 안전 위치로 자력 재스폰 |
| `P` | 일시정지 |
| `Esc` | 메뉴 복귀 확인 |
| `R` | 다시 시작 |

벽 위의 블록까지 한 칸만 남은 상태에서 `↑`을 계속 누르면 일반 벽타기
반복 모션에서 별도의 8프레임 모서리 오르기로 전환됩니다. 손을 블록 위에
짚고 상체를 앞으로 숙인 뒤, 팔로 아래를 눌러 무릎·골반·뒷발 순서로 몸을
올립니다. 이동 진행도와 프레임이 직접 연결되어 `↑`을 놓으면 현재 밀기 자세도
같이 멈춥니다.

게임 설명 화면은 이동·점프, 벽 액션, 기본 밀치기, 블록 플립뿐 아니라 일시정지,
재시작, 자력 재스폰, 게임 오버 뒤 메뉴 복귀 같은 특수 키도 움직이는 예시로 안내합니다.

## 압사와 낙하 판정

- 자연 낙하 블록이 한 칸 내려올 때 현재 캐릭터 애니메이션의 실제 몸통 픽셀을 검사합니다.
- 캐릭터가 낙하 블록과 보드 바닥 또는 고정 블록 사이에 직접 끼었을 때만 목숨이 1 감소합니다.
- 목숨이 남으면 캐릭터 윗면이 화면 위에서 48px 떨어진 위치에 나타나며, 고정·활성 블록과 `42×96px` 몸통이 겹치지 않는 열을 무작위로 선택합니다.
- 발밑이 비어 있으면 피해 없이 현재 기본 중력 배율 `1.0`을 유지하며 기존 조작은 그대로 사용할 수 있습니다.
- 블록의 좌우 이동·회전, 단순한 고정 블록 접촉, 보드 이탈은 목숨을 감소시키지 않습니다.

## 자력 재스폰

- 블록 아래에 갇혔을 때 `Q`를 1초간 유지하면 목숨 1개를 소비하고 상단 안전 열에 재스폰합니다.
- 누르는 동안 게임판 하단에 진행률이 표시되며, 1초 전에 놓으면 취소됩니다.
- 한 번 발동한 뒤에는 키를 놓아야 다시 사용할 수 있고 압착 무적 시간 중에도 실행됩니다.
- 마지막 목숨이거나 상단에 안전한 열이 없으면 게임 오버입니다.
- `OPTION → KEY CUSTOM`에서 자력 재스폰 키를 변경할 수 있습니다.

## 블록 플립 애니메이션

- 블록 플립은 기존 캐릭터 픽셀을 재배치한 전용 8프레임 시트를 사용합니다.
- 캐릭터가 바라보는 방향 기준으로 0.42초 동안 부드럽게 한 바퀴 돌며 중간에 되감기지 않습니다.
- 플립이 끝난 뒤 공중이면 상승·정점·하강 속도에 맞는 점프 프레임으로 이어지고, 착지했다면 지상 자세로 돌아옵니다.
- 블록 플립은 스태미나를 소비하지 않습니다. 성공 쿨타임은 2초이며, 공간 부족이나 범위 안에 블록이 없는 경우에도 모션을 재생하고 1초 쿨타임을 적용합니다.
- SRS 후보는 캐릭터의 실제 `42×90px` 충돌체를 장애물로 검사해 안전한 보정 위치만 사용합니다.
- 모든 후보가 캐릭터와 겹치면 블록을 회전시키지 않으며, 새 충돌체 동기화 전 상승 이동도 swept Rect로 차단합니다.

## 두 칸 높이 통로

- 캐릭터의 시각·논리 크기는 확대 좌표계에서 `48×96px`입니다.
- 물리 충돌체는 `42×90px`이며 중심을 아래로 3px 옮겨 기존 발 위치를 유지합니다.
- 따라서 정확히 96px 높이인 두 칸 통로에는 머리 위 6px 여유가 생기며, 고정 블록·보드 바닥·활성 블록 조합에서 같은 규칙으로 이동합니다.
- 낮은 천장에서 점프하면 상승만 막히고 좌우 이동은 계속됩니다. 블록 플립도 물리 충돌체를 회전시키지 않습니다.

## 1.5배 게임판과 HUD

- 게임 장면은 `560×1140px`, 게임판은 셀 `48px`의 10×20 구조인 `480×960px`입니다.
- 시작 화면은 기존 `960×800px` 레이아웃을 유지하고 게임 진입 시에만 창 크기가 바뀝니다.
- 우측 `400px` HUD에는 다음 블록, 점수·레벨·줄, 선택 캐릭터 초상, 목숨, 스태미나,
  특수 스킬과 블록 플립 쿨타임을 표시합니다.
- 게임 HUD의 조작법 영역은 제거했으며 스태미나와 블록 플립은 수치·텍스트와 막대를 함께 표시합니다.

## 스태미나 충전

- 스태미나는 공중이나 벽 매달리기 중에는 충전되지 않습니다.
- 보드 바닥, 고정 블록 또는 낙하 중 활성 블록의 윗면에 새로 착지하면 즉시 `100`으로 완충됩니다.
- 같은 발판에 계속 서 있는 동안에는 다시 충전되지 않으므로 지상 행동의 비용은 다음 착지까지 유지됩니다.
- 명상은 스태미나를 회복하지 않으며 캐릭터 정지와 블록 진행 속도 2배 효과만 유지합니다.

## 검증

Godot 4.7.1 기준 게임 로직·물리·시작 화면 테스트를 실행하고 Web release를 내보냅니다.

정식 itch.io 릴리스는 버전, commit, annotated tag, 빌드 로그, 산출물과 SHA-256을
하나로 연결하는 `release.ps1`을 사용합니다. 절차와 각 증거의 의미는
[`docs/RELEASE_EVIDENCE_KO.md`](docs/RELEASE_EVIDENCE_KO.md)에 정리되어 있습니다.

```powershell
pwsh -NoProfile -File .\release.ps1
```

`build_web.sh`는 Linux 개발 환경의 QA/export 진입점이며, 정식 태그 릴리스 증거는
`release.ps1`의 `build/releases/<version>-<commit>/` 결과를 기준으로 합니다.

```sh
./Godot_v4.7.1-stable_linux.x86_64 --headless --path . --import
./Godot_v4.7.1-stable_linux.x86_64 --headless --path . --script res://tests/main_game_test.gd
./Godot_v4.7.1-stable_linux.x86_64 --headless --path . --script res://start_screen/tests/main_ui_test.gd
./Godot_v4.7.1-stable_linux.x86_64 --headless --path . --export-release Web build/web/index.html
```

Web 결과는 `build/web/`에 생성됩니다. 브라우저 보안 정책 때문에 `index.html`을 파일로
직접 열지 말고 HTTP 정적 서버에서 실행해야 합니다.

게임 중 `Esc`를 누르면 메뉴 복귀 확인창이 표시됩니다. `↑`/`↓`로 `Yes`/`No`를
고르고 `Z`로 확인하며, `X`로 취소하고 게임으로 돌아갑니다.

설정은 `user://start_screen_settings.cfg`에 저장되며 키 커스텀과 BGM/SFX 볼륨 값을
다음 실행에 복원합니다. SFX 음원은 `assets/sfx/`에 포함되어 있습니다.

## 코드 구조

- `project.godot`: 프로젝트 설정과 시작 장면
- `scenes/`: 실제 게임 장면
- `scripts/`: 보드, 물리, 캐릭터, UI와 입력 코드
- `start_screen/`: 시작 메뉴, 튜토리얼과 키·볼륨 설정
- `assets/`: 블록·캐릭터 PNG 스프라이트와 SFX 음원
- `tests/`: 게임 로직과 물리 통합 테스트
- `docs/`: 게임 총정리(`GAME_OVERVIEW_KO.md`)와 온보딩·조사 기록

Godot의 `.godot/` 캐시와 빌드 결과물은 저장소에 포함하지 않습니다.
