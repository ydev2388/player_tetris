# Main 최종 통합 방향

현재 프로젝트 동작을 기준으로 설명 화면과 게임 오버 메뉴를 관리한다.

## 유지한 현재 동작

- `S` 블록 플립: 현재 SRS 보정, 충돌 검사, SFX, 쿨타임을 유지한다.
- `X` 일반 공격: 가까운 활성 블록을 즉시 한 칸 민다. 차지 단계와 UI는 없다. `S` 블록 플립은 같은 전방 펀치 hitbox를 사용하고 머리 위로 12px를 추가 판정한다.
- SFX 음원과 선택 효과음은 `assets/sfx/`에서 계속 사용한다.
- 자연 낙하로 발밑이 비어 있는 피격도 현재 규칙대로 기본 중력 배율 1.0을 유지한다.
- 게임 진행은 `MainGameController._physics_process()`에서 실행한다.

## 스테이지 기믹

- Stage 1-2는 새 active piece마다 20%, Stage 1-3은 33% 확률로 가시 piece를 만든다. 가시는 1초 ON/2초 OFF이며, ON 상태의 active piece를 X로 직접 때리거나 S 회전 킥에 성공하면 목숨 1개를 잃는다. 고정 즉시 가시 상태는 제거된다.
- 가시 overlay는 `assets/sprites/thron_sprite.png` 시트의 48px source 영역을 외곽 면별로 회전해 표시한다.
- Stage 1-4는 새 active piece마다 33% 확률로 가시 piece를 만들고, 실제 시간 10초마다 속박을 판정한다. 속박 시작 확률은 15%이며 실패할 때마다 다음 판정 확률이 5%p 증가하고, 성공하면 15%로 돌아간다. 활성 피스 접촉 중에는 속박하지 않으며, 바닥/비활성 블록 위·옆 또는 고정 블록/벽에 매달린 상태에서만 즉시 2초 속박한다. 공중이나 활성 피스 접촉 중 성공하면 다음 유효한 고정 지지면/매달림 때 적용한다. PAUSED에서는 모든 기믹 시간이 멈춘다.
- 속박 중에는 `assets/sprites/bind_sprite.png`의 덩굴 overlay를 캐릭터 주변에 표시한다.
- Stage 1-5의 기존 Boss 동작에는 기믹을 적용하지 않는다.

## 시작 화면 동작

- 시작 화면 게임 설명을 12FPS 애니메이션 5페이지로 확장했다. 키 표시는 설정의 실제 바인딩을 읽는다.
- 게임 오버에서 `Esc`를 누르면 `Yes`/`No` 확인창을 표시한다. 확인 중에는 physics process를 멈추며, `No`는 게임 오버 화면으로 돌아가고 `Yes`는 메인 메뉴로 복귀한다.

튜토리얼과 문서는 `V` 회전 킥 또는 당기기 동작을 전제로 하지 않는다. Windows 빌드는
`build_main.ps1`(또는 `build_main.bat`)에서 게임 테스트와 export를 순서대로 실행한다.
