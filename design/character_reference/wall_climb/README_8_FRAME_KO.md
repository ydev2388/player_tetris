# 일반인 벽 등반 8프레임 기준

- 실제 게임 아틀라스는 `normal_reference_atlas_v7.png`이다.
- 매달림 행은 128×128 타일 8개를 모두 사용한다.
- 프레임 1~4는 첫 번째 다리가 골반부터 올라가 발을 디디고 몸을 밀어 올리는 구간이다.
- 프레임 5~8은 체중을 넘긴 뒤 반대쪽 다리가 교차하여 같은 동작을 이어받는 구간이다.
- 무릎, 종아리, 발만 따로 회전하지 않고 골반부터 전체 다리가 연결된 포즈를 사용한다.
- 모든 프레임의 손은 오른쪽 벽 접촉선 X=87에 고정한다.
- 캐릭터 전신 높이, 머리와 몸통 크기, 128×128 캔버스 및 고정 배율 `(1, 1)`을 유지한다.
- 일반인만 8프레임을 재생하며, 아직 교체하지 않은 다른 7명은 기존 4프레임 매달림 행을 유지한다.
- 게임플레이 충돌은 스프라이트와 무관한 공통 42×90 고정 콜라이더를 계속 사용한다.
