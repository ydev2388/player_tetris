20명 캐릭터 최종 개략 설계

이 문서는 캐릭터 20명의 최종 개략 콘셉트를 텍스트 블록으로 정리한다. 이번 단계에서는 게임 코드와 스프라이트를 변경하지 않는다.

공통 설계 규칙

[명단]

전체 캐릭터 수 : 20명
별 해금         : 10명
조건 해금       : 10명

기존 아틀라스와 ID를 유지하는 캐릭터:
일반인, 복서, 방패병, 소방관, 청소부, 요리사

교체되는 기존 콘셉트:
노인   → 시계공
자석공 → 전자석 기사
과학자 → 테슬라 연구원

[공통 기본 공격: 1칸 밀치기]

대상      : 바라보는 방향의 바로 앞 블록 1개
결과      : 대상 블록을 바라보는 방향으로 정확히 1칸 이동
실패 조건 : 목적지가 다른 블록, 벽 또는 보드 밖일 때

모든 캐릭터의 기본 공격 사거리, 충돌 판정과 밀치기 결과는 같다.
캐릭터별 차이는 직업에 맞는 무기, 자세, 타격음과 시각 효과에서만 발생한다.
차지 공격, 연속 공격, 방향키 조합 공격은 사용하지 않는다.
칼날이나 도끼날이 있는 무기도 기본 공격으로 블록을 파괴하지 않는다.

[능력치]

공속     : 공통 회전킥의 성공 쿨타임
이동     : 좌우 최고 이동속도
점프     : 한 번의 점프로 오를 수 있는 높이
스태미나 : 시간 기반 행동의 스태미나 감소 속도와 특수 스킬 쿨타임 효율

수치 범위 : 1–10
1–2       : 명확한 핵심 약점
3–4       : 입문 캐릭터의 기본 수준
5–6       : 안정적인 표준 수준
7–8       : 확실히 뛰어난 수준
9–10      : 캐릭터 정체성을 결정하는 최고 수준

기본 공격의 재생속도와 쿨타임은 공속 수치와 관계없이 모든 캐릭터가 같다.
공격력, 블록 제어와 평균 능력치는 사용하지 않는다.
별은 능력치 총합이 아니라 해금 순서와 조작 난이도를 나타낸다.

공속 2  : 1.9초
공속 3  : 1.8초
공속 4  : 1.7초
공속 5  : 1.6초
공속 6  : 1.5초
공속 7  : 1.4초
공속 8  : 1.3초
공속 9  : 1.2초
공속 10 : 1.1초

계산식              : 2.1 - 공속 × 0.1초
회전킥 실패 쿨타임 : 성공 쿨타임의 50%

[이동: 좌우 최고속도]

이동 1  : 150px/s

계산식 : 140 + 이동 × 10px/s
가속도와 감속도는 모든 캐릭터가 같고 최고속도만 달라진다.

[점프: 상승 가능 높이]

점프 1–3 : 2칸
점프 4–6 : 3칸
점프 7–9 : 4칸
점프 10  : 5칸

기본 점프 능력치는 1이다.
캐릭터 데이터에는 각 구간의 시작값인 1, 4, 7, 10만 사용한다.
지상 점프와 벽 점프는 같은 점프 높이 단계를 사용한다.
점프키를 일찍 놓으면 현재처럼 상승 높이를 줄일 수 있다.

[스태미나: 지속 소모율]

스태미나 최대치는 모든 캐릭터가 100으로 같다.
능력치 1의 지속 소모율을 100%로 두고 1점마다 6%씩 감소한다.

스태미나 1  : 소모율 100%
스태미나 2  : 소모율 94%
스태미나 3  : 소모율 88%
스태미나 4  : 소모율 82%
스태미나 5  : 소모율 76%
스태미나 6  : 소모율 70%
스태미나 7  : 소모율 64%
스태미나 8  : 소모율 58%
스태미나 9  : 소모율 52%
스태미나 10 : 소모율 46%

계산식 : 기본 초당 소모량 × (1.0 - (스태미나 - 1) × 0.06)
적용 대상 : 벽 매달리기와 향후 추가되는 모든 시간 기반 스태미나 소모
미적용    : 특수 스킬의 즉시 차감 비용과 최대 스태미나 100

[스태미나: 특수 스킬 쿨타임]

캐릭터별 특수 스킬에 적힌 기존 쿨타임을 기본 쿨타임으로 사용한다.
스태미나 1의 쿨타임을 100%로 두고 1점마다 3%씩 감소한다.

스태미나 1  : 기본 쿨타임의 100%
스태미나 2  : 기본 쿨타임의 97%
스태미나 3  : 기본 쿨타임의 94%
스태미나 4  : 기본 쿨타임의 91%
스태미나 5  : 기본 쿨타임의 88%
스태미나 6  : 기본 쿨타임의 85%
스태미나 7  : 기본 쿨타임의 82%
스태미나 8  : 기본 쿨타임의 79%
스태미나 9  : 기본 쿨타임의 76%
스태미나 10 : 기본 쿨타임의 73%

계산식      : 기본 쿨타임 × (1.0 - (스태미나 - 1) × 0.03)
표시값      : 계산 결과를 소수점 첫째 자리로 반올림
최소 쿨타임 : 별도의 하한을 두지 않고 스태미나 10의 73%를 최댓값으로 사용

스태미나 능력치는 회전킥 쿨타임에는 영향을 주지 않는다.
회전킥 쿨타임은 공속 능력치만 사용한다.

[점프 능력치 배치]

점프 1 / 2칸:
일반인, 복서, 방패병, 소방관, 청소부, 요리사, 광부, 시계공, 폭파병

점프 4 / 3칸:
낚시꾼, 건축가, 전자석 기사, 테슬라 연구원, 로봇

점프 7 / 4칸:
마술사, 중력술사, 닌자, 도둑, 배달부

점프 10 / 5칸:
유령

입문형과 지상 작업형은 점프 1을 기본으로 사용한다.
블록 조작과 지형 활용이 중요한 캐릭터는 점프 4를 사용한다.
기동 자체가 정체성인 캐릭터는 점프 7을 사용한다.
최종 조건 해금 캐릭터인 유령만 점프 10을 사용한다.

[특수 스킬과 이모트]

캐릭터마다 특수 스킬은 정확히 1개만 존재한다.
패시브, 자동 발동 효과와 추가 능력은 사용하지 않는다.
특수 스킬의 성능은 범위, 대상 수, 이동 거리, 지속 시간, 비용,
쿨다운과 위험 조건으로 직접 표시한다.

ATTACK 행  : 직업별 무기로 수행하는 공통 1칸 밀치기 4프레임
SPECIAL 행 : 캐릭터별 특수 스킬 전용 이모트 8프레임

물, 연기, 폭발, 중력장처럼 오래 남는 효과는 캐릭터 아틀라스가 아니라
별도의 공용 VFX 아틀라스로 제작한다.

기본 무기   : 목제 연습봉
밀치기 모션 : 봉의 옆면을 양손으로 밀어 넣음

특수 스킬   : 전력 질주

비용        : 스태미나 25

특수 이모트 : 몸을 낮추고 힘차게 출발하는 자세

설계 핵심   : 이동, 점프와 공통 1칸 밀치기를 배우는 기준 캐릭터

효과        : 바라보는 방향으로 최대 6칸 돌진하고 처음 만난 블록을 1칸 민 뒤 정지
비용        : 스태미나 35
쿨다운      : 기본 7초 / 스태미나 6 적용 6.0초
제한        : 블록을 밀 공간이 없으면 블록 앞에서 멈추며 돌진 중 방향 전환 불가
특수 이모트 : 손수레 손잡이를 잡고 몸을 낮춰 출발하는 자세

설계 핵심   : 최고 이동속도를 위치 이동과 공격 기회로 바꾸는 지속 기동형

19. 로봇

캐릭터 ID   : robot
해금 방식   : 조건 해금
정확한 조건 : 한 게임에서 100,000점 달성
표시 힌트   : “여섯 자리 점수로 잠든 기계를 깨워라.”

외형        : 강철·황동 외장, 유압 팔, 가슴의 푸른 코어와 투사 장치
성격        : 감정 대신 최저 이동 횟수와 가장 안정적인 배열을 계산하는 기계
역할        : 영역 압축·융합 상위형
능력치      : 공속 7 / 이동 6 / 점프 4 / 스태미나 10

기본 무기   : 유압 손바닥
밀치기 모션 : 손바닥을 편 채 피스톤 압력으로 밀어냄

비용        : 스태미나 60
쿨다운      : 기본 13초 / 스태미나 10 적용 9.5초
제한        : 고정 장애물을 통과하거나 블록을 파괴하지 않음
특수 이모트 : 코어를 켜고 전방에 푸른 정렬 격자를 투사하는 자세

설계 핵심   : 청소부의 복구와 건축가의 정렬을 결합한 강력한 후반 상위형

20. 유령

캐릭터 ID   : ghost
해금 방식   : 조건 해금
정확한 조건 : 자력 재스폰을 사용하지 않고 한 게임에서 레벨 12 도달
표시 힌트   : “도움을 청하지 않고 가장 빠른 낙하를 견뎌라.”

외형        : 반투명 전통 복식, 푸른 도깨비불, 손목에서 이어지는 영혼 사슬
성격        : 블록과 사람의 경계를 이해하지 못하지만 완벽한 자리를 찾아 헤매는 존재
역할        : 직접 블록 조종·최종 융합형
능력치      : 공속 8 / 이동 9 / 점프 10 / 스태미나 8

기본 무기   : 영혼 사슬
밀치기 모션 : 사슬 고리를 블록에 대고 영력으로 밀어냄

특수 스킬   : 빙의
효과        : 전방 블록에 들어가 4초 동안 방향키로 0.4초마다 한 칸씩 직접 이동
비용        : 스태미나 60
쿨다운      : 기본 14초 / 스태미나 8 적용 11.1초
제한        : 빙의 중 기본 공격 불가, 빙의 블록 파괴 시 피해를 받고 즉시 종료
종료 처리   : 지속 시간이 끝나면 인접한 안전 칸으로 나옴
특수 이모트 : 몸이 안개처럼 풀려 블록 안으로 들어가는 자세

설계 핵심   : 도둑의 통과와 마술사의 위치 변경을 직접 조종으로 융합한 최종 개성형

최종 검증 기준

전체 캐릭터가 정확히 20명이어야 한다.
별 해금과 조건 해금이 각각 10명이어야 한다.
기존 6명의 이름, ID와 외형 자산 유지가 명시되어야 한다.
모든 캐릭터가 공속, 이동, 점프, 스태미나를 1–10 범위로 가져야 한다.
모든 점프 능력치는 1, 4, 7, 10 중 하나여야 한다.
기본형 캐릭터의 점프 능력치는 1이어야 한다.
모든 특수 스킬은 기본 쿨타임과 특수스킬 능력치 적용 쿨타임을 함께 표시해야 한다.
모든 캐릭터가 기본 무기, 1칸 밀치기 모션, 특수 스킬과 특수 이모트를 하나씩 가져야 한다.
공격력, 블록 제어와 평균 능력치를 캐릭터 성능 수치로 사용하지 않아야 한다.
조건 해금 캐릭터의 실제 판정과 표시 힌트가 일대일로 대응해야 한다.
기본 공격의 사거리와 결과가 캐릭터별 무기 때문에 달라지지 않아야 한다.
