# Kung Fu Tetris - Stage 4

플레이어가 테트로미노를 직접 조작하는 대신, 보드 안의 쿵푸 캐릭터로 블록을
밀고 당기고 회전시키는 Godot 4.7.1 프로젝트입니다.

## 실행 방법

1. Godot 4.7.1에서 이 저장소의 `project.godot`을 가져옵니다.
2. 프로젝트를 연 뒤 `F6`이 아니라 `F5`(프로젝트 실행)를 누릅니다.
3. 시작 화면에서 `GAME START`를 선택합니다.

명령행의 `godot` 실행 파일이 PATH에 등록된 환경에서는 저장소 루트에서 다음처럼
실행할 수도 있습니다.

```powershell
godot --path .
```

프로젝트 시작 장면은 `start_screen/scenes/start_screen.tscn`이며, 여기서
`scenes/main.tscn`을 불러옵니다.

## 주요 조작

| 입력 | 기능 |
| --- | --- |
| `←/→` 또는 `A/D` | 좌우 이동 |
| `Z` 또는 `Space` | 점프 |
| 바닥에서 `↓` 유지 | 명상, 블록 진행 속도 2배 |
| 벽에서 `C` 유지 | 매달리기 |
| 매달린 상태에서 `↑/↓` | 벽을 따라 이동 |
| 매달린 상태에서 `Z/Space` | 벽 점프 |
| `X` | 즉시 1칸 펀치 |
| `X` 0.4초/0.9초 유지 | 추가 펀치로 총 2칸/3칸 이동 |
| `S` | 가까운 활성 블록 당기기 |
| `V` | 가까운 활성 블록 회전 킥 |
| `P` 또는 `Esc` | 일시정지 |
| `R` | 다시 시작 |

## 실행 파일 구조

- `project.godot`: 프로젝트 설정과 시작 장면 지정
- `scenes/`: 실제 게임 장면
- `scripts/`: 보드, 게임, 캐릭터, 렌더링 코드
- `start_screen/`: 시작 메뉴, 튜토리얼, 키·볼륨 설정
- `assets/`: 블록과 캐릭터 PNG 스프라이트

`.godot/` 캐시와 플랫폼별 빌드 결과물은 저장소에 포함하지 않습니다. Godot이
프로젝트를 처음 열 때 필요한 import 캐시를 자동으로 생성합니다.
