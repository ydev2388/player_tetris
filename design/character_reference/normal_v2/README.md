# 일반인 v2 레퍼런스 제작 기준

이 폴더는 이후 캐릭터 스킨이 복제할 일반인 기준체의 ImageGen 원본과 검수 자료를 보존한다. 실제 게임 리소스는 `assets/sprites/characters/normal/normal_reference_atlas_v2.png`이다.

## 고정 계약

- 외형: 짧은 검은 머리, 열린 빨간 후드, 회색 티셔츠, 검은 바지, 흰 운동화
- 체형: 약 90px 전신, 약 15px 머리의 6등신 액션형
- 타일: 128×128, 중심 `(64, 64)`, 접지 발바닥 Y=109
- 행: 대기/이동 4, 공격 4, 매달림 4, 점프/낙하 8, 회전 8, 특수 8
- 방향: 오른쪽 원본, 왼쪽은 런타임 `flip_h`
- 조립: 프레임별 크기 정규화 금지. 각 상태 행은 하나의 축척만 공유한다.
- 런타임: `scale = Vector2.ONE`, 표시 오프셋 `(0, 3)`, 공통 42×90 물리 상자

## 생성 방식과 프롬프트 요약

모드는 ImageGen 이미지 생성이며, 기존 `normal_atlas.png`는 의상과 색상 정체성 참고로만 사용했다.

1. 모델 시트: 동일한 6등신 신체와 절대 관절 길이로 중립, 측면, 웅크림, 점프, 매달림 기준 포즈를 생성했다.
2. 상태 행: 모델 시트를 입력 레퍼런스로 사용해 `4/4/4/8/8/8` 프레임을 행별로 별도 생성했다.
3. 배경: 균일 크로마키 녹색을 요구하고 `remove_chroma_key.py`의 border 자동 키, soft matte, 12/220 임계값, despill로 RGBA를 만들었다.
4. 조립: `tools/build_normal_reference_atlas.py`가 각 행 공통 축척, 루트 앵커, Nearest 축소로 아틀라스를 재현한다.
5. 검증: `tools/validate_normal_reference_atlas.py`가 RGBA 크기, 36개 불투명 프레임, 타일 경계, 접지선과 서 있는 높이를 검사한다.

모든 생성 프롬프트에는 자세 변화는 관절 회전·가림으로만 표현하고 머리·몸통·팔다리를 확대하거나 축소하지 말 것, 평면 `#00FF00` 배경, 텍스트·격자·그림자·워터마크 금지, 선명한 제한 팔레트 픽셀 아트를 공통 조건으로 사용했다.
