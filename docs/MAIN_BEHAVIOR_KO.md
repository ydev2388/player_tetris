# Main 최종 통합 방향

현재 프로젝트 동작을 기준으로 설명 화면과 게임 메뉴를 관리한다.

## 유지한 현재 동작

- `X` 기본 밀치기: 캐릭터별 무기 모션으로 전방 hitbox의 활성 블록을 정확히 1칸 이동한다.
- `V` 특수 스킬: 일반인·청소부·시계공·닌자가 각자 하나의 스킬을 사용하며 스태미나와 전용 쿨다운을 적용한다.
- `S` 블록 플립: 현재 SRS 보정, 충돌 검사, SFX, 쿨타임을 유지한다.
- `X` 일반 공격: 가까운 활성 블록을 즉시 한 칸 민다. 차지 단계와 UI는 없다. `S` 블록 플립은 같은 전방 펀치 hitbox를 사용하고 머리 위로 12px를 추가 판정한다.
- SFX 음원과 선택 효과음은 `assets/sfx/`에서 계속 사용한다.
- 자연 낙하로 발밑이 비어 있는 피격도 현재 규칙대로 기본 중력 배율 1.0을 유지한다.
- 게임 진행은 `MainGameController._physics_process()`에서 실행한다.

## 스테이지 기믹

- Stage 1-2는 새 active piece마다 15%, Stage 1-3과 Stage 1-4는 25%, Stage 1-5는 33% 확률로 가시 piece를 만든다. 가시는 1초 ON/2초 OFF이며, ON 상태의 active piece를 X로 직접 때리거나 S 회전 킥에 성공하면 목숨 1개를 잃는다. 고정 즉시 가시 상태는 제거된다.
- 가시 overlay는 `assets/sprites/thron_sprite.png` 시트의 48px source 영역을 외곽 면별로 회전해 표시한다.
- Stage 1-4는 실제 시간 10초마다 기존 확률 누적 방식으로 2초 속박을 판정한다. 속박 시작 확률은 15%이며 실패할 때마다 다음 판정 확률이 5%p 증가하고, 성공하면 15%로 돌아간다. 활성 피스 접촉 중에는 속박하지 않으며, 바닥/비활성 블록 위·옆 또는 고정 블록/벽에 매달린 상태에서만 즉시 속박한다. 공중이나 활성 피스 접촉 중 성공하면 다음 유효한 고정 지지면/매달림 때 적용한다. Stage 1-5는 이 확률 속박을 사용하지 않고, 시작 10초 후부터 20초마다 보스 아래 랜덤 열에 블럭 한 칸 크기의 씨앗 3개를 뿌린다. 씨앗은 활성 피스에 닿으면 즉시 사라지고, 비활성 블록·바닥에 착지한 뒤 5초 후 사라지며, 플레이어가 닿거나 블럭이 고정될 때도 해당 씨앗이 사라지고 플레이어는 3초 동안 속박된다. PAUSED에서는 모든 기믹 시간이 멈춘다.
- 속박 중에는 `assets/sprites/bind_sprite.png`의 덩굴 overlay를 캐릭터 주변에 표시한다.
- Stage 1-5는 33% 가시 피스와 씨앗 접촉 시 3초 속박 기믹을 적용한다.

## 시작 화면 동작

- `GAME START` 뒤 네 캐릭터의 초상·능력치·무기·특수 스킬을 비교하고 확정한다.
- 시작 화면 게임 설명은 12FPS 애니메이션 5페이지이며 키 표시는 설정의 실제 바인딩을 읽는다.
- 게임 중 `Esc`를 누르면 `Yes`/`No` 확인창을 표시한다. 확인 중에는 physics process를 멈추며, `No`는 이전 게임 상태로 돌아가고 `Yes`는 메인 메뉴로 복귀한다.

튜토리얼과 문서는 이전 `V` 키 플립 또는 당기기 동작을 전제로 하지 않는다. Windows 빌드는
`build_main.ps1`(또는 `build_main.bat`)에서 게임 테스트와 export를 순서대로 실행한다.
