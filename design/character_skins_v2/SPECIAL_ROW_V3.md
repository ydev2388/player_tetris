# 고유 스킬 특수 행 v3

일반인의 전력 질주 행은 v2를 유지하고, 나머지 7명은 실제 고유 스킬을 읽을 수 있는 8프레임 특수 행으로 교체했다.

- 복서: 가드 브레이크 강펀치 후 정면 가드 복귀
- 방패병: 방패를 전방에 세우고 보호벽을 전개하는 자세
- 소방관: 호스를 잡고 전방 물길을 발사하는 자세
- 청소부: 발밑 행을 훑는 넓은 빗자루 쓸기
- 요리사: 팬을 낮춘 뒤 대각선으로 토스하고 회수
- 시계공: 태엽 장치를 꺼내 감고 전방으로 작동
- 닌자: 표창을 꺼내 던진 뒤 전투 자세로 복귀

`tools/build_character_special_rows.py`는 녹색 크로마 원본에서 8포즈를 추출해 각 행에 단 하나의 전역 배율만 적용한다. 몸과 연결되지 않은 보호벽·물줄기·반짝임·날아가는 표창은 이미 게임 코드가 별도 VFX로 그리므로 아틀라스 정규화 중 제거한다.

기존 v2의 1~5행은 그대로 복사하고 6행만 바꾼 `*_reference_atlas_v3.png`를 생성한다. 런타임의 고정 `scale=(1,1)`, 표시 오프셋 `(0,3)`, 공통 42×90 판정은 변하지 않는다.
