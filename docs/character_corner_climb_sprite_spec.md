# 캐릭터 공통 모서리 오르기 스프라이트 규격

이 규격은 이전 `9차 벽 오르기 스프라이트 추가` 작업에서 일반인 스프라이트를
제작할 때 사용한 판단 기준을 현재 일반인 `v12` 모서리 오르기 행에 맞춰 정리한
것이다. 복서나 다른 개별 캐릭터를 중간 기준으로 삼지 않는다.

## 기준 자산

- 동작 기준: 일반인 `normal_reference_atlas_v12.png`의 마지막 8프레임
- 외형 기준: 각 캐릭터가 현재 사용하는 단일 아틀라스의 기존 프레임
- 결과 규격: 캐릭터당 `1024×896` RGBA PNG 한 장
- 셀 규격: `128×128`, 8열 × 7행

## 8프레임 동작 계약

1. 양손 고정, 첫 무릎 들기
2. 팔로 당기기
3. 가슴이 모서리에 접근
4. 가슴이 윗면을 넘고 한쪽 다리는 아래에 남음
5. 손과 무릎을 윗면에 지지
6. 낮은 자세로 골반을 윗면에 옮김
7. 균형을 잡은 웅크림
8. 블록 위에 완전히 정착하여 섬

## 생성 및 채택 조건

- 생성 이미지는 포즈 연구 자료다. 원본의 첫 6개 행을 생성 결과로 교체하지 않는다.
- 각 캐릭터의 얼굴, 머리 크기, 몸통 크기, 복장, 장비, 팔레트를 유지한다.
- 일반인 8프레임의 높이 변화와 벽 쪽 진행 순서를 따른다.
- 모든 리샘플링은 최근접 보간을 사용하며 반투명 외곽은 정해진 알파 기준으로 정리한다.
- 각 프레임은 셀을 넘지 않고, 발/접촉 기준선과 벽 쪽 기준점을 공유한다.
- 머리-목-몸통이 연결되어야 하며 작은 고립 픽셀과 생성 배경을 제거한다.
- 프레임별 불투명 면적과 높이가 같은 캐릭터의 기존 체격에서 크게 벗어나면 채택하지 않는다.
- 좌우 오르기는 별도 이미지를 만들지 않고 하나의 행을 런타임에서 반전한다.
- 제작 참고 이미지와 분리 행은 런타임에서 참조하지 않는다. 최종 캐릭터 폴더에는 PNG가 한 장만 남아야 한다.

## 검수 조건

- 8개 프레임이 모두 비어 있지 않다.
- 모든 프레임에서 머리·목·몸통이 자연스럽게 연결된다.
- 2~4번의 실제 불투명 접촉 픽셀이 목표 블록 윗면에 자동으로 붙는다.
- 5~7번은 블록 위 정착 위치에서 미끄러지거나 튀지 않는다.
- 오른쪽과 왼쪽 등반 모두 같은 단일 Sprite2D와 같은 8프레임을 사용한다.
- 전체 게임 테스트, 전체 캐릭터 아틀라스 검사, 캐릭터별 좌우 실제 렌더링 검수를 통과한다.
