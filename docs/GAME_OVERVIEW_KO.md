# Block Fighter — 게임 총정리

> 현재 구현된 게임의 전체 내용을 한 문서로 정리한 스냅샷이다.
> 마지막 갱신: 2026-08-25 (`ui/simply-translate` 브랜치 기준).
> 코드가 바뀌면 이 문서도 함께 갱신한다. 상세 개발 기록은 `docs/research.md`,
> 과거 설계·조사 기록은 `docs/research_full.md`를 참고.
> (2026-08-24: `MAIN_BEHAVIOR_KO.md`·GODOT 함수/변수 REFERENCE 문서는
>  이 문서와 중복되어 삭제됨 — 고유 내용은 아래에 통합)

## 1. 게임 소개

- **장르**: Godot 4.7.1 블록 액션 게임 (Web 배포 우선)
- **컨셉**: 일반 테트리스와 다르다. 활성 피스를 직접 조작하지 않고,
  테트로미노가 계속 내려오는 **10×20 보드 안에서 캐릭터가 직접 움직여**
  블록을 밀고(X), 회전시키며(S), 탑을 오른다.
- **규모**: 탑 10개 층(1~10) + 도전 모드, 플레이어블 캐릭터 8종,
  패시브 상점(6종 × 최대 3레벨), 가시·결박·보스 씨앗 기믹, 보스전(5·10층)

## 2. 진행 흐름

```
MAIN(메인 메뉴)
 └→ FLOOR_SELECT (탑 선택: 위쪽에 6~10층, 아래쪽에 1~5층 세로 배치)
     └→ STAGE_SELECT (해당 테마의 층 카드 5개)
         └→ GAME (scenes/main.tscn)
뒤로가기: GAME → STAGE_SELECT → FLOOR_SELECT → MAIN (Esc/X)
```

- 모든 메뉴 UI는 `start_screen/scripts/start_screen.gd`에서 코드 생성.
- 스테이지 = 별도 씬 없음. `main.tscn` 하나를 인스턴스화하고
  `set_meta("stage_number", n)` / `set_meta("challenge_mode", bool)`로 전달.
- 규칙은 `scripts/game_controller.gd`의 `STAGE_GIMMICKS` 딕셔너리 하나가 전부.

## 3. 조작법

| 입력 | 기능 |
| --- | --- |
| `←/→` 또는 `A/D` | 좌우 이동 |
| `Z` 또는 `Space` | 점프 (벽 매달린 상태에서는 벽 점프) |
| 바닥에서 `↓` 유지 | 명상 — 블록 낙하 속도 2배 (스태미나 회복 없음) |
| 벽에서 `C` 유지 | 매달리기 (`↑/↓`로 벽 따라 이동) |
| `X` | 무기로 전방 블록 정확히 1칸 밀기 |
| `V` | 캐릭터별 특수 스킬 |
| `S` | 가까운 활성 블록 플립(SRS 회전) |
| `Q` 1초 유지 | 목숨 1개 소비, 상단 안전 위치로 자력 재스폰 |
| `P` | 일시정지 |
| `R` | 다시 시작 |
| `Esc` | 메뉴 복귀 확인창 |

- 키는 `OPTION → KEY CUSTOM`에서 변경 가능. 볼륨 설정도 OPTION에 있음.
- 언어: 메뉴는 한국어/영어/중국어 3개 국어, 게임 HUD는 한국어/영어만, 튜토리얼은 한국어 고정.
  `start_screen.gd`의 `_text()`가 ENGLISH_TEXT/CHINESE_TEXT 사전을 먼저 뒤지고, 없으면
  `scripts/localization.gd`(tr() 기반)로 폴백한다. `localization.gd` CN 사전은 CHINESE_TEXT를
  모두 커버하도록 동기화됨(2026-08-25).
- 시작 화면 게임 설명은 12FPS 애니메이션 5페이지이며 키 표시는 설정의 실제 바인딩을 읽는다.
- 튜토리얼·문서는 이전 `V` 키 플립 또는 당기기 동작을 전제로 하지 않는다.

## 4. 캐릭터 8종

능력치(공속/이동/점프/스태미나/특수스킬, 1~10)와 해금 조건은
`scripts/character_data.gd`의 `PROFILES`에서 관리한다.

| 캐릭터 | 포지션 | 해금 | 특수 스킬 (기본 쿨타임) |
| --- | --- | --- | --- |
| 일반인 | 균형형 | 처음부터 | 전력 질주 — 2초간 좌우 이속 +60% (7초) |
| 복서 | 정면 돌파형 | 별 3개 | 가드 브레이크 — 전방 블록 최대 3칸 밀기 (6초) |
| 방패병 | 정면 생존형 | 별 6개 | 전방 보호벽 — 세로 3칸 벽 2초 유지 (10초) |
| 소방관 | 낙하 경로 제어형 | 별 9개 | 중력 물길 — 3셀 물길 4초, 자동 낙하마다 물길 방향 1칸 이동 (13초) |
| 청소부 | 근거리 복구형 | 별 12개 | 대청소 — 발밑·좌우 노출 고정 블록 최대 3개 제거 (12초) |
| 성녀 | 성스러운 수호형 | 별 15개 | 성역의 가호 — 3초간 이속 +20% + 다음 기믹·보스 공격 1회 무효(압착 제외) (9초) |
| 시계공 | 시간 정지형 | 별 15개 | 정지 태엽 — 활성 블록과 다음 가시·결박·씨앗 발동 3초 지연 (12초) |
| 닌자 | 고속 원거리형 | 전 스테이지 무피해 | 표창 — 전방 6칸 표창으로 활성 블록 덩어리 1칸 밀기, 고정 블록에 막힘 (5초) |

## 5. 탑 구조와 스테이지 기믹

- **10개 층**, `FLOORS_PER_THEME = 5` → `stage_number % 5 == 0`인 층(5·10층)이 보스.
- 일반 층 생존 시간 90초, 보스 층 300초.
- 클리어 보상: 남은 시간 비례 별 획득, 층별 최고 별점(`stage_N_best_stars`) 저장.

| 층 | 시간 제한 | 가시 확률 | 결박 | 보스 씨앗 |
| --- | --- | --- | --- | --- |
| 1 | 90초 | - | - | - |
| 2 | 90초 | 15% | - | - |
| 3 | 90초 | 25% | - | - |
| 4 | 90초 | 25% | ○ (첫 지연 10초) | - |
| 5 (보스) | 300초 | 33% | ○ (첫 지연 5초) | ○ |
| 6 | 90초 | - | - | - |
| 7 | 90초 | 15% 얼음 블록 | - | - |
| 8 | 90초 | 25% 얼음 블록 | - | - |
| 9 | 90초 | 25% 얼음 블록 | - | - |
| 10 (보스) | 300초 | 33% 얼음 블록 | - | die 애니메이션 후 0.5초 대기 |

- **가시/얼음 블록**: `thorn_probability`로 active piece마다 확률을 정하며, 2~5층은 잔디 가시, 7~10층은 `assets/sprites/boss/6_10_boss/ice_block.png` 얼음 테두리를 블록 외곽에 붙여 표시한다.
  - **잔디 가시(1~6층)**: 1초 ON / 2초 OFF로 깜빡인다. ON 상태의 active piece를 X로 직접 때리거나 S 회전 킥에 성공하면 목숨 1개를 잃는다. 고정 즉시 가시 상태는 제거된다. overlay는 `grass_thron_sprite.png` 시트의 48px source 영역을 외곽 면별로 회전해 표시.
  - **얼음 블록(7~10층)**: 가시 ON/OFF 토글과 무관하게 **영구 지속**. 얼음 위에서는 가속도 10%·무입력 감속 3%로 미끄러지지만, 점프하면 공중에서는 일반 가속/감속으로 돌아온다. **공격해도 반사 피해가 없다**(잔디 가시만 반사). 얼음 블록에는 C-grab으로 매달릴 수 없다. 고정 얼음 셀은 파란 외곽선으로 구분 표시.
- **결박**: 10초 간격 검사, 확률 0.15(+실패마다 +0.05, 성공 시 0.15로 초기화)로 캐릭터 2초(보스 3초) 이동 불가. 활성 피스 접촉 중에는 속박하지 않으며, 바닥/비활성 블록 위·옆 또는 고정 블록/벽에 매달린 상태에서만 즉시 속박한다. 공중·접촉 중 성공하면 다음 유효한 고정 지지면/매달림 때 적용. 속박 중에는 `grass_bind_sprite.png` 덩굴 overlay 표시.
- **보스 씨앗(5층)**: 첫 지연 10초 후 20초 간격으로 3개 낙하, 수명 5초. 활성 피스에 닿으면 즉시 소멸, 비활성 블록·바닥 착지 후 5초 뒤 소멸, 플레이어 접촉 시 소멸 + 3초 속박.
- PAUSED에서는 모든 기믹 시간이 멈춘다.
- 6층 기믹 없음·테마별 차별화·탑 배경 스프라이트는 미구현(추후 예정).

### 보스전

- 보스 체력 3. 라인 삭제가 `damage_boss()`로 연결되어 정상 플레이로 클리어 가능하며, 10층 얼음 보스는 HP 0 즉시 die 애니메이션을 재생하고 0.5초 뒤 클리어한다.
- 10층 얼음 보스는 플레이어가 펀치/회전킥으로 직접 타격하면 `ice_hit.png` 오버레이가 1→2→3→4→3→2→1 프레임으로 재생된 뒤 사라진다(본체 스프라이트 유지, 체력 변화 없음, 가시 반격).
- 실패 시 실패 overlay를 통해 정상 복귀.

### 도전 모드

- 10층 클리어(별 1개 이상) 시 해금. 기믹 없음, 캐릭터 선택 제한 없음.

## 6. 해금 시스템

| 대상 | 조건 |
| --- | --- |
| 1층 | 항상 해금 |
| N층 (2~10) | N-1층에서 별 1개 이상 |
| 도전 모드 | 10층 클리어 |
| 복서~청소부 | 누적 별 3/6/9/12개 |
| 성녀·시계공 | 누적 별 15개 |
| 닌자 | 전 스테이지 무피해 클리어 |

## 7. 패시브 상점

- 클리어로 모은 **별을 재화**로 구매. 종류 6개 × 최대 3레벨, 레벨업 비용 = 다음 레벨 수(1★/2★/3★).
- 효과 단계 `PASSIVE_EFFECT_STEP = 0.05`:

| 패시브 | 효과 |
| --- | --- |
| 공속 | 기본 공격·회전킥(블록 플립) 쿨다운 감소 |
| 이동 | 좌우 이동 속도 증가 |
| 점프 | 점프 높이 증가 |
| 스태미나 | 벽 매달리기 소모량 감소 |
| 특수스킬 | 특수 스킬 쿨다운 감소 |
| 체력 | 레벨당 목숨 +1 |

- 세이브: `user://start_screen_settings.cfg` (ConfigFile). `[progress]` 섹션에
  `stage_1~10_best_stars`, 별 재화, 패시브 레벨 저장. 구버전(5층) 세이브는
  5층 클리어 시 6층 자동 해금 마이그레이션 지원.

## 8. 핵심 시스템 규칙

- **보드/HUD**: 게임 장면 560×1140px, 게임판은 셀 48px의 10×20 (480×960px),
  우측 HUD 400px(다음 블록, 점수·레벨·줄, 초상, 목숨, 스태미나, 쿨타임).
- **낙하 간격**: 셀당 0.4667s 고정 (명상 시 2배).
- **두 칸 통로**: 시각 몸통 48×96px, 물리 충돌체 42×90px → 96px 통로 통과 가능.
- **압사 판정**: 자연 낙하 블록에 실제 몸통 픽셀이 끼었을 때만 목숨 -1.
  블록 이동/회전·단순 접촉은 피해 없음. 부활 시 위에서 겹치지 않는 열로 무작위 재스폰.
- **블록 플립(S)**: SRS wall-kick 적용(`JLSTZ_KICKS`/`I_KICKS`), 스태미나 소모 없음,
  성공 쿨타임 2초 / 실패 1초.
- **스태미나**: 착지 시 즉시 100 완충, 같은 발판에서는 재충전 없음.
  공중·벽 매달리기 중엔 충전되지 않음.
- **자력 재스폰(Q)**: 1초 홀드로 목숨 1개 소비하고 상단 안전 열로 재스폰.
