# Main 최종 통합 방향

현재 프로젝트 동작을 기준으로 설명 화면과 게임 메뉴를 관리한다.

## 유지한 현재 동작

- `X` 기본 밀치기: 캐릭터별 무기 모션으로 전방 hitbox의 활성 블록을 정확히 1칸 이동한다.
- `V` 특수 스킬: 일반인·청소부·시계공·닌자가 각자 하나의 스킬을 사용하며 스태미나와 전용 쿨다운을 적용한다.
- `S` 블록 플립: 현재 SRS 보정, 충돌 검사, SFX, 쿨타임을 유지한다.
- SFX 음원과 선택 효과음은 `assets/sfx/`에서 계속 사용한다.
- 자연 낙하로 발밑이 비어 있는 피격도 현재 규칙대로 기본 중력 배율 1.0을 유지한다.
- 게임 진행은 `MainGameController._physics_process()`에서 실행한다.

## 시작 화면 동작

- `GAME START` 뒤 네 캐릭터의 초상·능력치·무기·특수 스킬을 비교하고 확정한다.
- 시작 화면 게임 설명은 12FPS 애니메이션 5페이지이며 키 표시는 설정의 실제 바인딩을 읽는다.
- 게임 중 `Esc`를 누르면 `Yes`/`No` 확인창을 표시한다. 확인 중에는 physics process를 멈추며, `No`는 이전 게임 상태로 돌아가고 `Yes`는 메인 메뉴로 복귀한다.

튜토리얼과 문서는 이전 `V` 키 플립 또는 당기기 동작을 전제로 하지 않는다. Windows 빌드는
`build_main.ps1`(또는 `build_main.bat`)에서 게임 테스트와 export를 순서대로 실행한다.
