# 점프·낙하 8프레임 기준

- 일반인 실제 게임 아틀라스는 `normal_reference_atlas_v8.png`이다.
- 8프레임은 도약, 상승, 정점, 초기 낙하, 안정 낙하, 빠른 낙하 순서로 구성한다.
- 모든 프레임은 공중 자세이며 깊은 웅크림, 착지 스쿼트, 지상 서기 자세를 포함하지 않는다.
- 마지막 프레임은 높은 곳에서 오래 떨어져도 계속 유지할 수 있는 전신 낙하 자세다.
- 일반인 8포즈에는 하나의 공통 배율만 적용해 웅크린 다리 때문에 머리나 몸통이 확대되지 않게 한다.
- 다른 7명도 기존 아틀라스의 잘못된 후반 웅크림·서기 프레임을 각 스킨의 안정 낙하 자세로 교체한다.
- 재생 프레임은 공중에 머문 시간이 아니라 실제 수직 속도로 선택한다.
- 게임플레이 판정은 스프라이트와 무관한 공통 42×90 고정 콜라이더를 유지한다.
