# 공통 콜라이더 캐릭터 스킨 v2

모든 캐릭터는 외형과 실루엣만 다르고 게임플레이 판정은 동일하다.

- 이동·벽·바닥·압착 판정: `Character/Collider`의 공통 42×90 직사각형, 중심 Y +3
- 스프라이트: 128×128 타일, 런타임 `scale = (1, 1)`, 시각 오프셋 `(0, 3)`
- 공통 발 기준: 접지 프레임의 발바닥 Y=109
- 애니메이션 계약: 대기/이동 4, 공격 4, 매달림 4, 점프/낙하 8, 회전 8, 특수 8
- 스프라이트 알파/장식/무기/방패/모자/망토는 이동 및 피격 판정에 사용하지 않음
- 공격 판정은 기존 기술별 코드 판정을 유지함

ImageGen built-in 모드로 일반인 v2를 포즈·비율 템플릿으로, 기존 7개 아틀라스를 의상·장비 참고로 사용했다. 각 결과는 균일한 녹색 크로마키 배경으로 생성한 뒤 설치된 제거 도구의 border 자동 키, soft matte, 12/220 임계값, despill로 RGBA 변환했다.

`tools/build_character_skin_atlases.py`는 캐릭터별 하나의 전역 축척만 적용하며 프레임별 자동 확대를 하지 않는다. `tools/validate_character_skin_atlases.py`는 8명 전부의 RGBA 규격, 필수 36프레임, 타일 경계, 서 있는 높이와 발 기준선을 검사한다.
