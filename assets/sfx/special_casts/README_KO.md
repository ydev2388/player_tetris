# 인게임 특수스킬 최종 효과음

특수스킬 입력이 정상 접수된 최초 시전 순간에 캐릭터별 WAV 하나를 재생한다.
각 음원 내부의 핵심 동작음은 실제 캐릭터 애니메이션과 스킬 판정 지연에 맞춰 배치했다.

| 캐릭터 | 음향 설계 | 핵심 동작 시점 |
|---|---|---:|
| 일반인 | 발 구름, 가속 압력, 좌우로 확장되는 질주 바람 | 즉시 |
| 복서 | 글러브 스윙, 짧은 샌드백 가죽 타격, 단단한 몸통 저역과 표면 복원음 | 0.25초 중심 |
| 방패병 | 방패 설치 충격, 세 칸 높이로 상승하는 에너지 벽 | 0.25초부터 |
| 소방관 | 밸브 개방, 호스 압력, 방향성 물줄기와 물방울 | 0.6초 중심 |
| 청소부 | 좌우 브러시 이동, 세 칸 제거음, 정리 완료 화음 | 0.4초 중심 |
| 성녀 | 따뜻한 기도 화음, 성역 상승, 배리어 팽창 | 0.3초 중심 |
| 시계공 | 래칫 태엽, 흡입되는 공간음, 저역 시간 고정 | 0.4초 중심 |
| 닌자 | 옷자락, 금속 준비음, 좌우로 통과하는 표창 | 0.25초 중심 |

- 48 kHz / 16-bit / stereo PCM WAV
- 실제 게임에서는 이 폴더의 8개 음원만 preload
- 기본 공격은 기존 `res://assets/sfx/02_block_punch.wav` 유지
- BGM 파일과 음악 전환 로직은 변경하지 않음
- `tools/compose_applied_special_sfx.py`로 재생성 가능
